# AcademiaOS Mobile Logo Animation

The login brand now uses a lightweight React Native `Animated` implementation of the supplied AcademiaOS sequential "devour" wordmark effect.

- Yellow circular accent travels left to right.
- Characters disappear sequentially and restore together.
- Uses the existing AcademiaOS navy/gold palette.
- Honors the platform reduced-motion preference.
- No authentication, API, Expo project, or secure-storage behavior was changed.
