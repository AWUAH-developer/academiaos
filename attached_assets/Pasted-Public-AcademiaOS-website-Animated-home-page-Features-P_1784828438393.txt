A safe daily-fee process should work like this:

Scheduled fee today: GHS 5.00
Learner absent: Yes
School rule: Carry forward
Today collected: GHS 0.00
Outstanding carried forward: GHS 5.00
New balance: Previous balance + GHS 5.00

The system must prevent duplicate charging when administrators refresh, reconnect, or sync an offline desktop.

Every daily charge should have an immutable identifier based on:

school + learner + fee type + date

Important instruction before submitting the prompt

Because your AcademiaOS project has custom workflows and has already been published, create a checkpoint and export a backup first.

Older Replit projects may require a one-time structural update before accepting another artifact. Replit says this update preserves the URL, database, secrets and domains, but heavily customised .replit workflows can prevent automatic conversion.

Do not tell Agent to complete everything in one uncontrolled task. Approve it phase by phase, beginning with the package and entitlement engine. The public website should follow only after the access restrictions are working.
